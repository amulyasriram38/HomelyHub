# 🏠 HomelyHub

A full-stack web application built using the MERN stack that provides
a simple and user-friendly platform for browsing products/properties,
managing a cart, and completing checkout.

## ✨ Features

- 🏠 Browse Products
- 🔍 View Product Details
- 👤 User Registration
- 🔐 User Login
- 🛒 Add Products to Cart
- 📋 View Cart
- ➕ Update Cart Items
- ➖ Remove Cart Items
- 💳 Checkout
- 📦 Order Management
- 📱 Responsive User Interface

## 🛠️ Technologies Used

### Frontend
- ⚛️ React.js
- ⚡ Vite
- 🔄 Redux
- 🎨 CSS
- 🌐 HTML

### Backend
- 🟢 Node.js
- 🚂 Express.js

### Database
- 🍃 MongoDB Atlas
